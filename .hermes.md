# Agentic Game Studio

This repository is an Agentic Game Studio. Preserve the user's final authority: explain trade-offs, request approval at documented gates, and keep collaboration decisions traceable.

## Hermes roles and skills

- Invoke repository skills with `/skill-name`; the setup command exposes `.agents/skills` through Hermes' external skill directories.
- Delegate named roles with `delegate_task`. Every delegated request must include the concrete goal, complete task context, the absolute project root, the stable role name with an instruction to read `.agents/roles/<role>.md` before acting, and the expected verdict or output contract. Hermes child agents start with isolated context, so never rely on inherited conversation history.
- Preserve all approval, collaboration, and write-permission gates embedded in the selected role or skill.

## Setup and maintenance

- Run `scripts/hermes-setup install` once per checkout, then use `scripts/hermes-setup check` to verify it. Hook execution still requires the user's explicit consent in Hermes; setup never grants or bypasses consent.
- Run `scripts/hermes-setup uninstall` to remove only entries installed for this checkout while retaining unrelated and subsequently added configuration.
- To preserve writes made through already-open file descriptors, setup retains displaced config and install-record inodes in the mode-0700 `$HERMES_HOME/agentic-game-studio-cas-history` directory and never deletes it automatically. Review that recovery history manually before removing it.
- `.claude` documents are the source. Regenerate with `python3 -m tools.platform_adapter.generate generate` and detect drift with `python3 -m tools.platform_adapter.generate check`.

## Native lifecycle differences

Hermes uses first-turn `pre_llm_call` context injection, native checkpoint and compression behavior, and native notifications. Its configurable shell hook protocol has no subagent start event, so only `subagent_stop` is registered for the agent audit trail. The active Hermes model and provider remain user-selected.

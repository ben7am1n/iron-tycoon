# Art Bible 补充：现代 2.5D 像素美术风格（《潜水员戴夫》视觉语法）

> **状态**: Approved — 2026-08-08（用户指定视觉方向）
> **定位**: art-bible.md 的风格升级补充。本文件定义的视觉语法优先于 art-bible.md 中与之冲突的纯 2D 像素方向。
> **核心理念**: 不是"复古像素画"，而是 **2D pixel + 3D art** 的混合——清晰的 2D 像素主体叠加有真实空间纵深的 3D/2.5D 场景。

## 1. 风格拆解（迁移视觉语法，不迁移内容符号）

| 维度 | 《潜水员戴夫》视觉语法 | 撸铁大亨的迁移 |
|---|---|---|
| 总体定位 | 现代技术包装的像素艺术，非 FC/SFC 硬件模拟 | 保留明显像素颗粒，允许现代光照/粒子/景深/复杂空间 |
| 2D/3D 关系 | 角色/道具 2D sprite；地形/背景立体空间 | 平面像素主体（设备/会员）+ 有纵深的环境（健身房） |
| 像素颗粒 | 中等偏粗像素块，轮廓易辨认，避免 1px 噪声 | 器械/会员 32×32 整数倍，粗颗粒可辨 |
| 造型 | 大形状优先，轮廓略夸张，归纳为少数色块 | 器械先简化剪影，再补关键特征（滚轮/把手） |
| 边缘 | 像素阶梯清晰，无传统抗锯齿柔滑 | 禁止插画式平滑曲线 |
| 角色比例 | 略卡通略敦实，头/躯干易读，肢体短 | 会员 2.5-3 头身，动作幅度明显 |
| 表情 | 像素少但眼睛/嘴/姿势表达强性格 | 会员低细节高表达（走路/排队/使用状态） |
| 色彩 | 基础环境色相统一，局部高饱和亮色做兴趣点 | Warm Cream/Sage/Sky/Peach 色域为主，Butter 亮色做锚点 |
| 明度关系 | 大面积中低对比背景 + 小面积高亮主体 | 器械/会员/招牌跳出背景；墙与地板低对比 |
| 空间层级 | 前景-中景-远景，远处雾化/降饱和/降对比 | 健身房三层：设备前景 / 会员中景 / 墙窗远景 |
| 光照 | 现代柔和体积光/环境光/发光物/局部 bloom（克制） | 暖光环境光 + 窗口光 + 灯具发光，服务像素可读性 |
| 阴影 | 大块暗面，不追求物理写实微小阴影 | 设备下大暗面 + 区域柔和暗角 |
| 材质 | 高度概括：金属冷色高光/木材色带/石材块面 | 器械金属高光、地板木纹色带、墙砖块面 |
| 环境密度 | 大量简单小型视觉单元堆丰富度 | 绿植/镜子/水机/海报/灯饰像素模块 |
| 气氛 | 舒适幽默冒险，允许神秘危险 | 温暖社区健身房 + 少量"蜕变前破旧"细节 |
| UI | 现代深色半透明面板/亮色描边/粗字体/图标 | 现代游戏信息设计，不严格做古老 RPG 像素框 |

## 2. 可直接执行的风格规范

### 核心视觉原则
画面不是纯粹复古 16-bit 像素画，而是**清晰的 2D 像素主体 + 具有真实空间纵深的 3D/2.5D 环境**的混合视觉。

### 像素主体（设备/会员/可交互物）
- 中等偏粗颗粒手工像素造型；轮廓清楚，像素阶梯边缘可见，无平滑插画式抗锯齿
- 大色块 + 剪影识别为第一优先级，减少微小纹理；复杂对象概括成少量辨识结构
- 人物轻微夸张、敦实、友好卡通比例；面部细节少，但姿态/轮廓/关键像素强表情

### 场景环境（健身房空间）
- 明显前景/中景/远景层次；大型结构（墙/地形/器械框架）允许 3D 体积，表面像素化简化
- 强视差层级 + 空气透视：近景较暗清晰对比高；中景主体；远景降对比/降饱和/受环境色与雾影响
- 地面用 TileMapLayer（Godot 4.7 中 TileMap 已弃用）做木地板/胶地板 tile

### 色彩结构（70/20/10 法则）
- ~70% 画面统一克制环境色（Warm Cream 底 + Sage/Sky/Peach 区域）
- ~20% 次级色彩变化（设备主体色）
- ~10% 高饱和视觉锚点（Butter 灯光/招牌/状态高亮/Dusty Rose 警示）

### 光照与阴影
- 现代氛围光（非复古像素光照）：柔和环境光、体积光、雾气、局部辉光、发光物、轻微 bloom
- 所有效果克制，服务像素主体可读性
- 阴影用大块明暗色块，不追求物理写实

### 材质概括
- 金属：少量冷色高光；木材：简单色带；石材：块面变化；玻璃/水：少量反光 + 色相变化
- 禁止照片纹理、PBR 微表面、超真实反射

### 环境丰富度
- 模块化装饰：绿植/镜子/水机/海报/灯具等小型简单像素物件组合丰富度
- 留白优先（art-bible §6 延续），不堆砌

## 3. 负面约束（禁止）

- 纯粹复古 8-bit/16-bit 屏幕感
- 所有东西完全平面的传统横版 pixel art
- 高清动漫插画 / 矢量卡通 / HD-2D 极端景深 + 强烈电影级 bloom
- 写实 PBR 材质 / 照片纹理 / 超高密度像素细节
- 柔滑无像素感的角色轮廓
- 所有区域同等鲜艳 / 同等清晰
- 黑色粗描边覆盖所有对象
- 低多边形 voxel / Minecraft 方块造型
- 赛博朋克式过度霓虹
- 过度阴暗、灰黑、严肃的电影写实质感

## 4. 最关键的判断标准（验收）

改造成功后应满足三点：

1. **第一眼看空间**：有明显立体纵深、视差、环境雾和现代氛围光
2. **第二眼看物体**：人物和关键物件明显是粗颗粒、手工归纳过的 2D 像素 sprite
3. **第三眼看整体**：不是"怀旧像素滤镜"，而是**故意让复古像素语言与现代场景渲染同时存在**

> 迁移的是视觉语法，不是《潜水员戴夫》的内容符号（海洋/珊瑚等题材元素不迁移）。

## 5. 与既有 art-bible 的关系

- art-bible.md 的**色彩系统（§4）、语义色彩、区域色系、UI 语言（§7）** 继续有效
- art-bible 的 **环境标准（§6）** 升级：从平面 TileMap 变为"3D 体积环境 + 像素化表面 + 三层纵深"
- 冲突时以本文件为准

## 1. Visual Identity Statement (视觉身份陈述)

**一句话视觉规则（黄金法则）：**
> **"一眼读懂功能，一眼看出变好。"** —— 任何画面，玩家都应能瞬间分辨每个区域在做什么，并能立刻感到场馆比之前更好了。

**支撑原则（每条锚定一个支柱，并附设计测试）：**

1. **可读优先于华丽**（锚定支柱3"一眼看懂"）
   *设计测试：当"更精致的细节"与"更清晰的功能识别"冲突时，永远选清晰。*

2. **温暖零焦虑的基调**（锚定支柱2"松弛不紧绷"）
   *设计测试：当一个视觉元素可能让人紧张（刺眼红光、闪烁、拥挤压迫）时，改用柔和、留白、圆润的表达。*

3. **蜕变必须可见**（锚定支柱4"看得见的蜕变"）
   *设计测试：当一次升级只改了数值时，追问"画面上变了什么？"——必须有肉眼可见的正向变化。*

4. **空间即主角**（锚定支柱1"空间即玩法"）
   *设计测试：当美术资源与"让布局关系更清晰"冲突时（如器械占位、区域边界、动线），优先服务布局可读性。*

---

## 2. Visual Identity Summary

一款温暖、干净、俯视/轻等距的**治愈像素风**健身房经营游戏。画面像一个精心整理过的娃娃屋：柔和明亮的色调、圆润友好的像素小人、清晰的功能分区。核心美术任务不是炫技，而是**让"空间关系"和"逐步变好"这两件事一眼可读、令人放松、值得截图**。

## 4. Color Palette (色彩系统)

### 设计原则
以**温暖中性底 + 柔和功能点缀色**区分区域；避免高饱和警示色（红/闪烁）用于常态，以维持松弛感（支柱2）。

### Primary Palette
| Name | Hex | Usage |
| ---- | --- | ----- |
| Warm Cream（暖奶油） | `#F4E9D8` | 地板/背景底色，营造温暖留白 |
| Soft Charcoal（柔炭） | `#3C3A42` | 描边/文字/像素轮廓（非纯黑，降低对比压力） |
| Sage（鼠尾草绿） | `#8FBF9F` | 力量区 / 正向满意度 / "好"的语义 |
| Sky（天空蓝） | `#8EC5E8` | 有氧区 / 平静 / 信息类语义 |
| Peach（蜜桃橙） | `#F2B486` | 团课/社交区 / 温暖强调 |
| Butter（黄油黄） | `#F5D97B` | 金钱/奖励/里程碑高光 |
| Dusty Rose（灰玫瑰） | `#E0A0A0` | 拥挤/需注意（柔和版"警示"，绝不刺眼） |

### Emotional Color Mapping（按游戏状态）
| Game State | Dominant Colors | Mood |
| ---------- | --------------- | ---- |
| 经营/布置（主状态） | Warm Cream + 各区点缀色 | 平静、专注、掌控 |
| 破旧初始场馆 | 低饱和灰调 + 少量暖色 | 朴素、有潜力（不是"糟糕/惩罚"） |
| 升级/蜕变时刻 | Butter 高光 + 饱和度整体回升 | 满足、成就、"值得截图" |
| 拥挤/瓶颈提示 | Dusty Rose 柔和标注 | 温和提醒，非焦虑 |
| 里程碑/金牌场馆 | Butter + Peach 暖金氛围 | 庆祝、温暖高潮 |

### 语义色彩词汇
- **绿（Sage）= 好/满意/力量区**；**蓝（Sky）= 平静/信息/有氧**；**黄（Butter）= 金钱/奖励**；**玫瑰（Dusty Rose）= 需注意（拥挤）**。
- **色盲安全**：Sage↔Dusty Rose（绿↔红系）是关键易混对。所有"满意/拥挤"状态**必须**同时用**图标 + 形状**（如笑脸/汗滴图标、实心/斜纹填充）背书，绝不单靠颜色。

## 5. Art Style

### Rendering Style
像素艺术（Pixel Art）。俯视偏轻等距（top-down with light dimetric），Godot 中 texture filter = **Nearest**，避免缩放模糊（4.7 的最近邻视口缩放仅作用于 3D，故 2D 像素锐利靠导入设置的 Nearest 保证）。

### Proportions
- **像素小人**：约 2.5–3 头身的 Q 版比例，圆润、友好、无攻击性。
- **器械**：占据清晰的整数网格格子（1×1 / 1×2 / 2×2），轮廓一眼可辨其类型。
- **网格**：单格建议 32×32 或 16×16 逻辑像素（在架构阶段最终确定），所有资源对齐网格。

### Level of Detail
游戏相机距离下，器械以**剪影 + 一个标志性细节**即可识别（如跑步机的履带线、深蹲架的立柱）。会员在缩放下靠**颜色块 + 姿态**区分，不依赖面部细节。

### Visual Hierarchy（引导视线）
1. **最高**：正在交互/被选中的器械、拥挤/瓶颈提示。
2. **中**：会员小人与其动线。
3. **低（后退）**：地板、墙面、装饰——低对比、柔和，永远不与功能元素争夺注意力。

## 6. Environment Art Standards (环境/关卡美术)

- **建筑风格**：现代都市小场馆——砖墙、大玻璃窗、木地板/胶地板质感，暖光。传达"社区健身房"的亲切感，而非高冷精品健身房。
- **纹理哲学**：手绘像素质感（非 PBR）；用**明度而非高饱和**表现材质差异，维持柔和基调。
- **Tileset/模块化**：墙、地板、窗、门为可复用 tile，基于 **`TileMapLayer`**（Godot 4.7 中 `TileMap` 已弃用，一律用 `TileMapLayer`，一层一节点）。
- **区域边界**：不同功能区（力量/有氧/团课）用**地板色块 + 柔和描边**区分，让"分区"一眼可读（支柱1）。
- **环境叙事**：破旧初始态用裂缝、褪色、闪烁灯管、生锈器械讲"这里需要你"；升级后换成明亮灯、绿植、干净地面——**蜕变靠环境细节讲，无需文字**（支柱4）。
- **Prop 密度**：留白优先。装饰（绿植、镜子、水机、海报）点缀而非堆砌，避免拥挤压迫感。

## 7. UI/HUD Visual Direction (UI 视觉语言)

*(art-director 视觉方向 + ux 可读性对齐，已内联合并；无冲突。)*

- **风格**：屏幕空间 HUD（非全 diegetic），但视觉上与世界同源——圆角、暖色、像素描边，像"世界的一部分"而非冷冰冰的系统层。
- **排版**：像素/圆润无衬线字体，友好、可爱但清晰；建立清晰字号层级（标题/数值/说明三级）。中文需选用支持完整字形的像素友好字体（架构阶段确认字体资源）。
- **图标**：**带描边的填充式**图标（outlined-fill），每个功能区/器械/状态都有专属图标——支撑"图标+颜色双通道"的色盲安全策略。
- **动效手感**：轻弹性、柔和缓入缓出；拖放器械时有吸附"咔哒"反馈 + 轻微缩放弹跳。利用 **Godot 4.7 的 Control 偏移变换**做按钮/面板动画而不被容器布局重置；用 **`tween_await()`** 串联反馈序列。
- **拖放交互反馈（核心）**：拖动器械时显示网格吸附高亮、区域效果预览浮层（如"+舒适度""拥挤+2"）、非法位置用柔和玫瑰色而非刺眼红。
- **数据可视化叠加**：拥挤度/动线热力图用 **Godot 4.7 的 `DrawableTexture2D`** 直接绘制叠加层，柔和半透明，可开关，绝不常驻刺激视觉。
- **HUD 密度**：低。常态只显示关键信息（金钱、满意度、时间）；细节按需弹出，维持松弛（支柱2）。

## 8. Asset Production Standards (资产生产标准)

*(art-director 偏好 + technical-artist 引擎约束，已内联合并。)*

### Naming Convention
`[category]_[name]_[variant]_[state].[ext]`
例：`equip_treadmill_basic_idle.png`、`member_casual_female_walk.png`、`ui_icon_satisfaction.png`、`env_floor_wood_a.png`
- 类别前缀：`equip_`（器械）/ `member_`（会员）/ `ui_`（界面）/ `env_`（环境）/ `vfx_`（特效）
- 全部 **snake_case**，与项目 GDScript 命名规范一致。

### Texture Standards
| Category | Max Resolution | Format | Color Space | 备注 |
| -------- | -------------- | ------ | ----------- | ---- |
| 会员/器械精灵 | 单帧对齐网格（如 32×32 的整数倍） | PNG（无损、透明） | sRGB | 导入 filter = Nearest, mipmaps off |
| 环境 Tile | 单 tile 16×16 或 32×32 | PNG | sRGB | 用于 TileMapLayer / TileSet |
| UI | 按 @1x 像素设计，整数缩放 | PNG | sRGB | 九宫格（NinePatchRect）用于面板 |
| VFX 帧 | ≤ 64×64/帧 | PNG 序列或 AtlasTexture | sRGB | 帧数从简 |

- **纹理集**：会员/器械/UI 分别打包为 AtlasTexture/精灵表，控制 draw call（性能预算：典型场景 < 200 draw calls，60fps / 16.6ms）。

### Animation Standards
- **帧率**：像素动画 8–12 fps 观感（用 AnimatedSprite2D / SpriteFrames）；游戏逻辑仍 60fps。
- **会员动画集**：`idle` / `walk` / `use_equipment` / `happy`（最小集，MVP 足够）。
- **UI 过渡**：120–250ms，柔和缓动；避免生硬或过长。

## 9. VFX Standards (特效标准)

- **风格**：极简、柔和、像素化。特效服务"反馈与治愈"，绝不制造视觉噪音或紧张（支柱2）。
- **正反馈**：器械放置成功 → 轻微星光/闪粉 + 吸附咔哒；满意度上升 → 柔和上浮的 `+` 心形/笑脸像素粒子。
- **金钱/奖励**：Butter 黄的硬币像素粒子轻弹跳。
- **蜕变时刻**：升级完成 → 一次温暖的"擦亮/焕新"扫光（sweep），配合饱和度回升，强化"看得见的蜕变"。
- **拥挤提示**：柔和的玫瑰色汗滴/波纹图标，温和脉动而非闪烁。
- **禁止**：屏幕震动、刺眼闪光、快速闪烁、血腥/爆炸类——全部违背治愈基调。

## Accessibility (无障碍)

- **图标 + 颜色双通道**：所有游戏状态（满意/拥挤/区域类型）必须同时用图标/形状表达，绝不单靠颜色（Sage↔Dusty Rose 是关键易混对）。
- **色盲安全**：提供色盲友好检查；关键语义对通过形状/图标/填充纹理区分。
- **最小文字尺寸**：正文 ≥ 16px @1080p（像素字体按整数缩放，保证锐利可读）。
- **高对比选项**：提供可选高对比 UI 主题（加重描边、提升文字/背景对比）。
- **无闪烁**：默认无快速闪烁元素（光敏安全）。

## Style Prohibitions (风格禁区)

明确不做（与反支柱一致）：
- ❌ 写实/3D 渲染风格 —— 坚持 2D 治愈像素。
- ❌ 高饱和撞色、刺眼红光、快速闪烁 —— 破坏松弛基调。
- ❌ 屏幕震动 / 暴力冲击特效 —— 违背治愈定位。
- ❌ 密集信息轰炸的 HUD —— 违背"一眼看懂"与"松弛"。
- ❌ 阴暗、压抑、恐怖或脏乱到令人不适的画面 —— 破旧≠肮脏压抑，破旧应"有潜力、待焕新"。
- ❌ `TileMap` 节点（引擎层禁区）—— 一律用 `TileMapLayer`（Godot 4.7 弃用规则）。

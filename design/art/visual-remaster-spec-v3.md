# 视觉重制规格：现代高完成度 2.5D 像素健身房（V3）

> **状态**: Approved — 2026-08-08（用户详细反馈，替代 v2 增量换色方向）
> **定位**: 本文件是视觉重制的**唯一权威规格**。art-bible.md 与 art-bible-25d-style.md 的色彩/语义继续有效，但渲染架构、场景密度、空间层级以本文件为准。
> **核心理念**: 不是"在高清画布上换色 + 加像素图标"，而是**从场景渲染逻辑上重新设计**——真正的低分辨率像素世界 + 现代光照氛围 + 高环境密度。

## 0. 总目标

把健身房模拟器做成"现代高完成度 2.5D 像素游戏"。核心视觉特征：

1. 世界本身是真正的低分辨率像素画（不是高清画布上摆几个 pixel icon）
2. 场景具有丰富的环境细节和明显空间纵深
3. 角色和健身器械采用夸张、清楚、手绘感的 pixel sprite
4. 环境使用现代动态光照、阴影、局部辉光和空气感
5. 保持健身房经营模拟游戏的信息可读性

## 1. 禁止彩色开发网格（最高优先级）

**最终游戏画面中禁止直接出现纯色格子。**

- Tile grid 只能作为底层逻辑存在，视觉层必须覆盖完整的地面材质
- 区域区别通过**材质、地板纹理、边缘压条、家具、灯光、墙面装饰**表达
- 禁止：绿色方块=A区 / 蓝色方块=B区 / 橙色方块=C区（prototype 表达）

**区域地面材质规范**：

| 区域 | 材质 | 细节 |
|------|------|------|
| 力量训练区 | 深灰橡胶地垫 | 多个略有色差的像素块、接缝、磨损、汗渍、高光、轻微污迹 |
| 有氧区 | 偏暖灰或蓝灰地面 | 细小重复纹理、边缘压条 |
| 瑜伽区 | 暖色木地板 | 明显木板方向、少量像素化木纹 |
| 公共通道 | 浅灰/暖灰瓷砖 | 比训练区亮，非纯色，有砖缝 |

## 2. 统一的低分辨率世界渲染

**不要在 1280×800 高清画布中直接绘制世界。**

- World Layer 内部使用低分辨率逻辑画布：**320×200 / 384×240 / 426×240**
- 通过 **nearest-neighbor 放大**到窗口尺寸
- 保证：人物边缘真实 pixel stair-step；器械边缘真正像素结构；墙/地纹理同一 pixel density；阴影轮廓符合像素网格

**禁止**：高清 CSS 圆角矩形世界元素、高清 anti-aliasing 世界元素、像素角色+高清矢量地板、像素器械+平滑 UI 背景。

- **WORLD 层统一属于同一个 pixel space**
- **UI 可以更高分辨率，游戏世界不能**

**技术实现方向**：`SubViewport`（低分辨率）→ 贴到 `TextureRect`/`Sprite2D`（nearest filter），或自定义 `_draw` 到低分辨率贴图后放大。

## 3. 显著增加环境资产密度

当前约 80% 画面是空白米黄背景。**必须增加永久存在的环境结构**（非可购买设备）：

- 墙壁、立柱、窗户、入口、前台、储物柜、饮水机、垃圾桶、毛巾架、消防栓、通风口
- 吊灯、壁灯、海报、健身广告、植物、储物架、空调、墙钟、镜子、电线槽、音响、门、踢脚线、管道

**验收标准**：即使移除所有玩家购买的设备，画面依然是一间完整、有生活感、有故事的健身房。

## 4. 明确的空间层级（至少三层）

| 层 | 内容 | 处理 |
|-----|------|------|
| **BACKGROUND** | 墙面、窗户、大型镜子、通风管、墙上广告、远处家具 | 较低对比度 |
| **GAMEPLAY** | 人物、跑步机、卧推架、瑜伽垫、自行车、前台、主要交互对象 | 更清楚、更鲜艳、轮廓更明确 |
| **FOREGROUND** | 靠近镜头的墙角、大型植物、柱子、设备局部、悬挂标识 | 允许轻微遮挡角色 |

- 远处元素：降对比、略降饱和
- 前景物体允许对人物产生轻微遮挡
- 制造真实深度，不是棋盘

## 5. 设备画成"小型场景物件"（非图标）

每件设备要有真实存在感，3/4 top-down 视角下能看出朝向。

**跑步机**：深灰机身、大型倾斜跑带、浅灰金属扶手、控制面板、少量青蓝显示灯、地面投影、关键高光像素、明显前后结构。
**卧推架**：杠铃、配重片、支架、长凳、地面阴影、金属高光。
**自行车**：座椅、飞轮、车把、踏板、机架、小显示屏。
**瑜伽垫**：卷起边缘、轻微表面纹理、角色使用姿势关系。

每件设备至少：**3-5 个主要颜色层级 + 明确高光 + 明确阴影 + contact shadow + 小范围 accent color**。禁止纯灰色剪影。

## 6. 器械和人物有明显方向光

- 统一室内主光：顶部暖白色健身房灯
- 世界基础色调：偏暖、稍暗
- 主要照明：顶部柔和暖白光
- 阴影：偏冷、偏蓝灰
- 高光：暖黄色/奶白色
- 设备下方明显但柔和的 contact shadow
- 墙边比中心区域稍暗
- 窗口附近：斜向自然光
- 部分机器显示屏：青蓝/绿色局部 emissive pixels
- 饮水机/售货机/招牌：少量局部辉光

**IMPORTANT**：不做真实 3D PBR 灯光，最终仍必须像 pixel art。光影作用是增加体积感和氛围，不是变成 Unity 3D 场景。

## 7. 色彩：暖环境 + 冷阴影 + 高饱和重点色

当前色彩太接近 pastel prototype。重新建立 palette：

| 用途 | 色系 |
|------|------|
| 背景基底 | 暖灰、奶油灰、低饱和棕 |
| 阴影 | 深蓝灰、青灰 |
| 器械 | 炭灰、深蓝灰、浅灰金属 |
| 木材 | 暖橙棕 |
| 植物 | 中等饱和绿 |
| Accent | 黄、橙、青蓝 |

**高饱和色只用于**：设备屏幕、互动提示、重要道具、人物服装、小型装饰、UI 提示。
**禁止**：整个地板高饱和绿/蓝/橙。

## 8. 人物重新设计

人物不能是几个像素组成的微型符号，要成为画面重要视觉主体。**sprite 视觉尺寸明显增大**。

- 短而敦实、略夸张比例、头稍大、肩膀明显、四肢较短、轮廓极易识别
- 每人：清晰发型、皮肤色块、衣服主色、裤子/短裤、鞋、阴影侧、高光侧
- 面部：眼睛、眉毛、嘴（几个像素即可）
- **动作必须非常有表现力**（夸张、清楚、有节奏的 pixel animation，非平滑 skeletal）：
  - 跑步：身体前倾、手臂摆动、腿部明显循环
  - 卧推：杠铃上下运动、身体轻微形变、结束时坐起
  - 累：弯腰、擦汗、喘气、头顶小汗滴
  - 满意：挺胸、举手、小闪光

## 9. 微型动态元素（画面不能静止）

持续存在少量（不要全屏粒子）：
- 空调出风粒子、窗户光尘、角色汗滴
- 设备显示灯闪烁、跑步机传送带动画、自行车飞轮转动
- 电视画面变化、植物轻微摆动、水杯闪光
- 角色移动轻微动作反馈

这些细节让场景感觉"活着"。

## 10. UI 重新处理（移除 debug 工具感）

**移除**：GymManager (DEBUG) 标题、macOS 红黄绿窗口控制、大面积深灰圆角 Web UI panel、过细现代字体、规整网页按钮布局。

**改为**：
- 深蓝灰/炭灰像素面板、轻微不规则像素边缘、2-3px 明确描边、暖黄 accent、米白文字、小型 pixel icon、明显层级
- 避免大量圆角；按钮接近游戏 HUD panel，不是 HTML/CSS dashboard
- 底部购买栏：设备 pixel sprite 缩略图 + 名称 + 价格 + 状态
- Hover：设备略提亮 + 黄色像素描边 + 轻微上移

## 11. 轮廓线粗细按材质调整（非统一 outline）

- 人物：深色轮廓明显
- 机器：部分深蓝灰轮廓，高光侧可不用完整描边
- 地板：基本无深色 outline
- 墙壁：依赖明暗块区分
- 装饰：允许局部轮廓
- **禁止**：每个 tile 都框起来

## 12. 场景 storytelling

每块区域像真实使用过的空间：
- 跑步机旁：水瓶、毛巾、跑步海报
- 力量区：散落小配重、杠铃架、粉笔盒、镜子
- 瑜伽区：植物、小音箱、卷起的备用瑜伽垫、暖色灯
- 自行车区：墙上计时器、风扇、水杯架

这些元素不需要交互，但对目标艺术风格非常重要。

## 13. 视觉密度标准（禁止大块空白）

正常镜头中：
- 大型结构：每画面 5-10 个
- 中型场景物件：15-30 个
- 小型环境装饰：30-60 个

通过大量简单 pixel asset 组合出丰富世界。

## 14. 保持经营游戏可读性

- 可购买设备 > 环境装饰（交互设备饱和度略高、轮廓更清楚；背景降饱和降对比）
- Hover：黄色像素轮廓
- Selected：小型地面 glow / outline
- **Placement mode 才显示 tile grid；正常经营模式完全隐藏 grid**

## 15. 最终视觉印象

**应该像**：一款已完成商业美术制作的像素经营游戏。
- 第一眼：丰富、温暖、有大量生活细节的健身房
- 第二眼：人物/器械/家具是精心制作的 pixel sprite
- 第三眼：灯光、阴影、局部辉光、空间层次等现代效果

**关键词**：handcrafted pixel art / modern 2.5D pixel game / chunky expressive sprites / rich environmental storytelling / warm indoor lighting / cool colored shadows / pixelated volumetric atmosphere / dense environmental props / clear silhouettes / strong depth separation / subtle emissive pixels / cozy but lively / slightly comedic character proportions / high production-value indie game

**绝对避免**：flat pastel prototype graphics / colored debug tiles / large empty beige background / CSS dashboard aesthetics / HTML-style rounded rectangles / macOS window chrome / developer UI / vector icon aesthetic / equipment as tiny symbols / single-color floor areas / uniform lighting / pure top-down chessboard / thin modern UI typography / anti-aliased world sprites / photorealistic rendering / PBR materials / voxel graphics / Minecraft blocks / generic mobile tycoon aesthetics / flat corporate illustration / oversized empty canvas / every tile outlined / identical gray outlines

## 附录 V3.1：从"程序生成感"转向"手绘游戏感"（用户 2026-08-09 反馈）

> 总目标：**不要继续增加细节。当前最大问题不是细节少，而是视觉语言错误。把它从"像素化的室内设计图"转换为"一个由艺术家手绘完成的 2.5D 像素经营游戏场景"。**

### 已确认正确（保留）
- 完整空间结构（墙/分区/地板材质/植物/灯光/器械/阴影）✓
- 前中后空间感（不再是棋盘）✓

### 5 个优先级任务（严格按此顺序，勿一次全做）

**P1 — Camera 改 2.5D 斜俯视（最高优先）**
- 从纯正交俯视（RimWorld/SimCity/编辑器感）→ 30-45 度斜俯视
- 物体同时显示：顶面 + 正面 + 侧面（有体积）
- 家具/器械必须有体积；人物不是棋盘棋子
- 目标：diorama 小世界，非平面地图

**P2 — 设备 sprite 重做（真物体，非图标）**
- 跑步机：跑带/扶手/控制台/支撑柱/阴影
- 卧推：长凳厚度/杠铃/杠铃片/架子
- 动感单车：飞轮/座椅/脚踏/把手
- 最低要求：3 个方向面（top/front/side）+ 5 层颜色（base/shadow/outline/highlight/accent）+ contact shadow
- 设备离开地面，不贴地图

**P3 — Pixel density 改手绘感**
- 从"规则几何像素"（完美直线/矩形/等宽边框/重复规则纹理）→"手绘 pixel art"
- 增加：不规则像素边缘、手工小色块、局部磨损、随机细节、不完全对称
- 大型结构由多个 pixel cluster 组成，非一个完整矩形填充
- 例：地板 = 多个深灰/灰蓝/暖灰 pixel cluster，非纯色 100×100 区域
- 让每个区域像艺术家逐块绘制，而非程序生成

**P4 — 灯光改 pixel based lighting**
- 移除大面积圆形 gradient 光斑（Photoshop 光圈感）
- 改为：墙附近稍暗、灯下稍亮、设备附近局部高光、发光屏幕小范围亮色
- 光影响材质和颜色，不是画透明白色圆

**P5 — 颜色加高饱和视觉焦点**
- 保持 70% 环境低饱和，但加入 10-15 个高饱和焦点
- 例：蓝色设备屏幕/黄色水杯/红色广告牌/绿色植物/橙色健身服/彩色瑜伽用品
- 不要让整个画面灰蒙蒙

### 负面约束（补充）
- 禁止：完美直线/完美矩形/等宽边框/重复规则纹理/纯色大面积填充/圆形半透明光斑/CSS 仪表盘 UI/DEBUG 文字/macOS 窗口按钮/设备贴地图/人物像棋子

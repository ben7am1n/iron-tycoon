# 玩家交互与三天内容脚本

日期：2026-09-06。状态：设计稿，尚未实现。计时、费用和判定以[玩法GDD](../../../design/gdd/gym-adventure.md)为准。

## 主角操作与输入归属

| 场景／模式 | 输入 | 反馈与限制 |
|---|---|---|
| PREP漫游 | WASD／方向键，E互动，B布置 | 主角可以聊天和查看课程板；世界无营业倒计时 |
| PREP布置 | 左键拖放，R旋转，右键／Esc取消，B退出 | 不同时驱动主角移动；显示访问格、幽灵和冲突原因 |
| OUTING探索 | WASD／方向键，E互动 | 与阿洛交谈、进入挑战入口、返回馆内 |
| OUTING挑战 | WASD，1走／2慢跑／3冲刺 | 1/2/3为配速；显示体力和目标速度，绝非时间倍速 |
| SERVICE漫游 | WASD／方向键，E互动，H热图，Space暂停 | 营业固定1x；B显示营业中不能布置的说明 |
| 指导选择 | 1／2／3选保持／放缓／休息，鼠标同效 | 选择后进入节奏窗；未选满2秒进入AUTO并关闭 |
| 指导节奏 | E或屏幕按钮，一次确认 | 前台目标固定高亮；六秒周期窗，只采第一有效操作 |
| CLOSE | 鼠标／键盘焦点、E与人物交流 | 无时间压力；账单显示已发生流水，不重新发钱 |
| 全局 | Esc菜单、F5保存 | Esc先关闭最上层可取消面板，再暂停；F5先暂停再保存 |

输入从当前模式唯一分发，不让UI点击穿透到放置／世界互动。课程决策面板用1/2/3时，公园配速输入不订阅。按键回显只对一次pressed生效，echo忽略；释放、失焦与模式切换清理按住状态。

布置期间，鼠标释放在商店、HUD或窗口外也要结束拖拽：窗口内按最终有效世界位置完成或取消；窗口外／失焦取消并恢复原位置。不得只依赖_unhandled_input收到release。非法放置时保留错误提示至下一次移动／取消或1.5秒后；不要在结束拖拽的同一状态边沿删掉待显示提示。

## 主要界面

### 1. 模式入口与继续游戏

两个入口“社区故事”“自由经营”；继续游戏明确标出模式、日序、阶段。新社区故事不覆盖已有沙盒槽。坏存档显示具体错误和返回入口，不清空当前存档。

### 2. 开店准备

画面常态保留主角、场馆与课程板。顶部“第1天 · 准备”，右侧现金；下方一个主目标“准备今晚的新手课”。点击课程板打开两张课程卡，显示需求器械、四席和每席24元；力量课未就绪时显示“需要摆放卧推架”，可跳到该器械购买入口。

绑定器械显示编号／名称与世界高亮。按钮“检查并出发”“留馆准备营业”。校验失败列出可定位原因，提供“去调整”和“恢复基础布局”。恢复基础布局先展示两件借用设备和将收纳的自有设备清单，确认后执行，取消不改状态。

### 3. 公园挑战

正式挑战面板：最长3分钟、今日一次正式成绩、练习不限。显示路线三个检查点和目标配速。可跳过挑战直接聊人物；离开不扣钱。

挑战HUD最多显示体力、当前／目标配速、剩余时间和下个检查点方向。目标带同时有“走路／慢跑／提速”文字。没有同时叠加大地图、技能树和道具背包。

挑战结束显示“今日成绩”与一个具体建议，例如“前段太急了，先让呼吸稳下来”；低分不出现失败封锁。继续键回公园，后续去留由玩家决定。

### 4. 营业HUD

顶部：第几天／营业剩余时间、现金、一个当前目标。下方建造栏隐藏。课程开始前显示简短通知“课程将在30秒后开始”，所需器械有预约标记。

课程中显示“第2/4段 · 换站”及四个小人状态；常态不挂四条百分比进度条。H热图可开关，访问受阻图标始终显示。Inspect点击后打开实际详情面板：设备类型、借用／自有、当前使用者、课程预约和本日等待；不保留无接收方的空按钮。

### 5. 一对一指导

会员头顶一个请求图标，靠近后显示E和名字；同屏最多一个请求。打开面板显示明确状态：“呼吸急促，想把速度降下来。”

操作分两步：选保持／放缓／休息，再按节奏。选择限2秒、节奏限6秒，总计8秒；会继续消耗营业时间。辅助模式将节奏步骤改成不限精度的一次确认(仍在6秒窗内)，timing固定0.5，不阻断人物故事。完全忽略由老邱处理。

### 6. 课程决策

与个别指导共用选择词，但没有追加节奏小游戏。两次各10秒，正确反馈来自文字／状态快照。未响应时显示“老邱接过节奏”，立即回到营业，不弹惩罚面板。

### 7. 打烊

第一屏只显示普通访问收入、课程收入、今日支出、结余；每项可展开去重交易。课程评价用“训练完成／到站节奏／指导”三个分量解释，不把Q冒充现金收益。

第二屏是一段人物交流或来信。第三日达成包场后播放结尾；还未达成则显示“明天再约一次”，进入补充营业日。场馆改造预览展示灯牌／墙面／前台灯三处变化与120元价格；确认前不扣款。

## 三天逐段脚本

### 第1天：重新开门

**目标：学会主角移动、布置、一次外出和基础营业。**

| 节点 | 内容与操作 | 系统产出／回退 |
|---|---|---|
| 门口开场 | 林师傅擦灯牌：“能亮。就是它还没想起来怎么亮。”程教练推门，镜头落到旧馆 | 展示借用两设备与280元，进入PREP |
| 老邱教学 | “先留条路。练完腿的人，不想再翻山越岭。”玩家移动瑜伽垫，看访问点 | 不强制购买；失败可取消／恢复 |
| 选课与出发 | 默认耐力课，购买单车或卧推架均可；首次确认课程绑定 | 没买设备也能继续；出发前检查 |
| 公园初见 | 阿洛跑到路边喘气：“唱副歌的时候，我总比鼓手先结束。” | `aluo_met`一次；正式挑战可参加或略过 |
| 配速挑战 | 三段路与配速提示；不用另开教学小游戏 | 提交每日result；低分仍可邀请阿洛 |
| 第一晚 | 正常八访客＋四人课；已MET的阿洛占课程一席，未MET用通用会员替补；第一个指导请求教学 | 自动基础服务兜底，收入取实际完成 |
| 打烊 | 阿洛：“今天唱不出来了，不过好像能把一句话说完了。” | 本人训练≥30秒且班结束才记`aluo_first_class`；未完成则约下次 |

未见过阿洛的分支：第一晚打烊他来问课程，发相同初见事件；第二天首次上课。不能同时重复公园与门口初见。

### 第2天：每个人有自己的节奏

**目标：体验课程选择和布局改变结果；让会员成为熟人。**

| 节点 | 内容与操作 | 系统产出／回退 |
|---|---|---|
| 准备 | 显示昨天到站问题的一个定位建议；玩家可换课程／买另一器械 | 只引用真实事件，昨天无课程则显示普通动线建议 |
| 公园 | 阿洛带来两句歌词；再次挑战或直接聊天 | 每日result独立，初见事件不重发 |
| 营业 | 第二次主角指导；老邱接管一次被忽略的课堂提示 | 让自动帮助在视觉上成立 |
| 打烊邀请 | FIRST_CLASS已达成且当前日≥2，阿洛：“他们说想来试试。四个人，不带音箱……先不带。” | `band_invitation`一次；未达条件则练习后重试，首日不发邀请 |
| 改造提议 | 林师傅演示灯牌：“我修好了，它现在认识晚上了。” | 显示120元预览；取消／买不起不锁邀请 |

### 第3天：乐队包场

**目标：把准备、人员关系、课程和场馆变化汇成一个高潮。**

| 节点 | 内容与操作 | 系统产出／回退 |
|---|---|---|
| 准备 | band_invitation已提交、band_event_complete未提交且玩家确认预约才将课程四席替换成乐队；覆盖已参加但未达标的重试，三位队友用通用会员身体和名字 | 未满足则按是否已认识阿洛生成普通课程名册；普通八访客仍保留，总预约12 |
| 公园 | 阿洛热身，谈今晚的小目标 | 仍可略过，不加入新地图 |
| 包场营业 | 复用所选课程四块；关键拍点加入轻音乐层和人物反应 | 不更改Q公式，不加隐藏难度 |
| 课程结束 | 四人达训练门槛后，阿洛用练习的呼吸唱完一句原创短旋律 | `band_event_complete`一次，三段关键画演出 |
| 打烊 | 老邱把课程板摆正；林师傅端详招牌；阿洛贴上合影 | 完成切片。未完成则重排，不假装成功 |

结尾对白草稿：程教练：“明天还来？”阿洛：“我把鼓手也带上。”老邱：“他不是今天来了吗？”阿洛：“今天来的是吉他手。鼓手还在找停车位。”

## 永久事件和重试

| event_id | 前置 | 提交效果 | 重复行为 |
|---|---|---|---|
| aluo_met | 公园初见或门口替补 | 人物可见、档案解锁 | 重播对话无奖励 |
| aluo_first_class | 阿洛完成至少30秒训练 | 第一训练故事达成 | 更新评价，不发第二次事件 |
| band_invitation | first_class已达成且日序≥2的打烊 | 包场可在下一PREP预约 | 取消后可重排 |
| band_event_attended | 包场开始，四席到场 | 记参与事实 | 下一次仍可冲完成 |
| band_event_complete | 四席均≥30秒 | 结尾、合影、切片完成状态 | 回顾不重复写状态 |
| gym_renovated | 现金≥120且未改造 | 扣120、外观升级 | 已拥有，禁止重复购买 |

高课程质量触发额外表情与一行对白，没有额外现金或剧情权限。馆内“关系成长”目前通过事件／反馈表达，首版不增加另一条需要刷满的经验条。

## 体验验收

- UX-01：只看界面提示，试玩者能在首日完成选课、检查、外出、返回和营业。
- UX-02：键盘与鼠标两种方式都能完成选择／取消／保存；UI点击不触发世界放置。
- UX-03：在HUD、商店、窗口外松开拖拽，不残留DRAGGING状态。
- UX-04：开／关H热图有实际画面变化；Inspect展示当前真实设备身份。
- UX-05：忽略所有可选操作仍能继续；主动介入能看到明确不同的角色反应。
- UX-06：第1／2／3天至少各出现一个新的可见内容节点；主故事没有同一对白重复发奖励。
- UX-07：对话、挑战和课程中保存后冷启动，继续时阶段与目标一致；恢复默认暂停。
- UX-08：鼠标移出letterbox时无错误格选择；文本放大后按钮仍可见且可操作。

# 街角健身房：美术、动画与声音规格 v1

日期：2026-09-06。状态：样板制作基线，尚无引擎内成品验收。角色身份和范围以[设计入口](README.md)为准。

## 目标镜头

一间社区老馆占据画面主体。程教练在卧推区俯身指导；后侧一位会员骑车；窗边阿洛用手打节拍；入口老邱观察，林师傅带工具进门。暖灯与窗外蓝色街景形成层次。会员的姿态、器械接触和开放通道应在正常游戏镜头下清楚可辨。

这张“营业中的房间”同时验收空间深度、主角识别、器械朝向、人体动画、UI密度与夜间可读性。先完成这个镜头，再扩展装修样式。

## 现有管线与样板约束

- 沿用Godot 2D、统一ObliqueProjection、SubViewport与独立CanvasLayer UI，不迁引擎。
- 先沿用当前代码的投影参数；源代码实际值为基准，历史规格中38°等注释不再当制作参数。
- 样板世界426×240；在1280×720显示为1278×720、左右各1px中性留边，严格3倍nearest。其他窗口使用可容纳的最大整数比例并居中，UI锚定同一展示矩形。
- 首版窗口最小尺寸1280×720；中文UI至少18px显示字号，推荐20–24px；支持文本放大，布局随之重排。不能仅增字号导致选项裁切。
- 输入先扣除letterbox偏移再除显示倍率，再走统一投影逆变换；拖拽、点击、地面高亮都用同一个变换。
- WORLD_SCALE=0.75下不得把手工像素人物再任意压缩。精灵交付以最终SubViewport像素为单位，在投影后的脚底位置按整数尺寸绘制，或通过等效补偿保证像素尺度。
- 若人物在标准窗口仍不可读，再用完全相同场景、人物比例和灯光进行640×360 A/B。只改一个变量并记录判断，之后才修订本规范和主GDD。

## 空间组成

| 层 | 内容 | 可读性规则 |
|---|---|---|
| 背景 | 暖灰墙、窗、镜子、海报、储物柜；窗外街道 | 对比低于人物，纹理按物件聚簇，不铺满噪声 |
| 营业层 | 会员、教练、器械、训练垫、候课点 | 明度和轮廓最清楚，器械下有接触影 |
| 前景 | 局部门框、植物、入口灯牌 | 不覆盖关键动作；遮住主角脚底时淡出 |

中央保持可走通道；前台靠入口、有氧靠后窗、力量在侧墙、拉伸靠采光面。这个安排表达空间功能，最终格位须通过开店与课程到站验证。

装饰不制造未声明碰撞。地面铺橡胶／木板／瓷砖材质；网格只在布置模式作为辅助显示。物件密度由故事和留白决定，不沿用“越多越精致”的数量指标。

## 人物造型与规格

四位角色沿用设计入口中的体型／发型／服饰识别锚点。主角青绿外套、阿洛砖红、老邱酒红、林师傅钴蓝配黄帽；近似颜色的角色仍必须靠轮廓区分。

- 通用帧画布32×40最终视口像素；站立可见轮廓约18–24×28–34px。宽姿势可扩展画布，但脚底锚点不变。
- 正常镜头优先身体姿态；近景表现眼睛、眉毛和嘴。对白头像另画，不直接放大模糊的小人。
- 朝向统一为场景的四个地面方向；主要角色不左右镜像，以免头发、包、服装边和光照换侧。
- 肤色、体型和衣服可有差异；首版普通会员使用一套身体动画换装。命名角色进入器械必须另做体型适配，不能以“换颜色”替代。
- 程教练动作语言：平视、倾听、指示节奏、短促握拳；不用夸张炫耀动作替代指导。

## 四器械的动作接触

每个朝向必须交付：静态主体、前后遮挡层、访问点、脚底锚点、双手／双脚接触点和进出动作。地面旋转改变逻辑方向，渲染选择对应图稿，不把同一精灵在屏幕上转90°。

| 器械 | 必须对齐 | 不能接受的结果 |
|---|---|---|
| 跑步机 | 跑带落脚面、双手交互点、下机位置 | 脚踩在带外、人在整个机器上漂移 |
| 单车 | 坐垫、手把、左右踏板，远腿／车架／近腿分层 | 脚不碰踏板、整个人上下抖动代替骑行 |
| 卧推架 | 头背凳面、双手杠铃、地面双脚 | 杠穿手、杆与手不同步、突然变成立姿 |
| 瑜伽垫 | 膝、掌、脚与垫面 | 宽幅伸展穿进相邻器械或挡住通道 |

程序确认逻辑位置；美术的姿态偏移只能改变表现，不绕过访问格约束。设备描述数据提供接触点而非在WorldCanvas中按设备名逐个硬编码。

## 最低动画制作账

按独立绘制的完整帧计，不把调色替换计为新的动作。以下是计划量，需通过首批样板测得工时。

| 项目 | 单位帧数 | 数量 | 合计 |
|---|---:|---:|---:|
| 四位主要角色：待机2＋走路6＋说话4＋反应4，四方向 | 64 | 4 | 256 |
| 主角指导，6帧四方向 | 24 | 1 | 24 |
| 通用会员跑步机：入4＋循环8＋出4，四方向 | 64 | 1 | 64 |
| 通用会员单车：入4＋循环8＋出4，四方向 | 64 | 1 | 64 |
| 通用会员卧推：入4＋循环10＋出4，四方向 | 72 | 1 | 72 |
| 通用会员瑜伽：入4＋循环6＋出4，四方向 | 56 | 1 | 56 |
| 跑带／飞轮循环，各4帧四方向 | 16 | 2 | 32 |
| 阿洛课程体型适配：上述四种器械完整动作 | 256 | 1 | 256 |
| 公园主角：慢跑6＋冲刺8，四方向 | 56 | 1 | 56 |
| **动作帧预算小计** | | | **880** |

另需四人对白头像各3表情=12幅，三段重要事件各6幅关键画=18幅。通用会员基础待机／行走可复用主要角色的骨架节奏，但成品换装图集、器械静态四朝向、环境图块及UI不计入880帧，应单独计工时。

第一批只生产程教练待机／行走／指导、通用会员跑步机与瑜伽动作、两台器械四朝向。验证后再画阿洛体型及其他器械。普通对称服装可镜像；命名人物、非对称装备和受方向光影响的图稿不得直接镜像。

待机／行走8–10fps，锻炼8–12fps；成功反应保留关键帧停顿。缩放和粒子不能替代身体实际做动作。

## 光色与环境变化

| 时段 | 主光 | 阴影／窗外 | 氛围 |
|---|---|---|---|
| 准备／白天 | 清晰的浅暖窗光 | 蓝灰接触影 | 房间干净、可读，适合调整 |
| 返回／傍晚 | 低饱和琥珀窗光＋室内灯 | 街景开始偏蓝 | 营业期待感 |
| 营业／夜间 | 顶部暖白灯 | 窗外靛蓝、墙边偏冷 | 热闹但能看清脸、手、脚 |
| 打烊 | 前台与局部灯保留 | 大面积静态柔和暗部 | 聊天与收获感 |

禁止全屏透明白光池、密集散点噪声和大面积bloom。金属用少量冷高光，木材用成组色带，设备屏幕用局部青色。一次外观改造具体改变三处：更干净墙面、入口新灯牌、前台暖灯；不只是加总亮度。

## 界面与视线

营业HUD只保留阶段／剩余时间、现金、当天一个目标；操作提示位于目标附近和右下角。建造栏仅PREP布置模式显示。热图H可切换，拖拽时降权；访问点堵塞提示始终可见。

指导提示同时提供文字、符号和姿态。钱、质量和关系分别使用硬币、课程评语、人物反应，避免一串相似数字飘字。效果减少选项关闭屏幕晃动、闪烁和额外粒子，不改变操作判定。

## 声音清单

- 两材质脚步各3变体；门铃与开关门；配重轻碰／落架；跑带启动、停止和循环；单车循环。
- 布料／坐下／起身、三档喘息、教练短口令、请求提示、柔和成功和错过反馈。
- 对话推进、选择确认／取消、保存完成、窗外街道、室内通风和稀疏人声。
- 一条营业主题，底层＋节奏＋活跃层；按实际在场人数混音，暂停不触发更多事件。进入指导时降低环境与音乐以听清口令。
- 所有关键声音同时有视觉提示；音量独立调节。器械声不按每个会员无限叠加，超过同类声音上限则降低优先级。

## 样板验收

| ID | 测法 | 通过条件 |
|---|---|---|
| ART-01 | 标准窗口、无名字的四人黑剪影 | 5名测试者至少4人可在对照后分辨四角色 |
| ART-02 | 四器械四方向，逐帧查看使用循环及进出 | 手／脚／坐点不脱离，不穿过关键杆件 |
| ART-03 | 同房间同镜头三时段截图，隐藏时钟 | 可辨白天／傍晚／夜间，人物服饰仍可区分 |
| ART-04 | 主角走完整馆，逐帧检查 | 像素尺度稳定，脚底不跳，点击地格对应正确 |
| ART-05 | 移除购买器械后截图 | 仍能辨认有前台、储物、采光和生活痕迹的健身房 |
| ART-06 | 正常课程，不开热图 | 能看出谁训练、谁等待、哪里堵；关键通道可辨 |
| ART-07 | 静音、文本放大、效果减少 | 所有关键互动可完成，UI无裁切 |

## 概念图的用途

概念图预定用于讨论构图、光色、人物存在感，不能作为游戏截图、像素图集、严格格位或动画接触验收证据。本轮两次生成均遇到网络错误，尚无图片产物；本包交付的是美术规格和可复用提示词。

生成记录和原始提示词见[image-prompt.md](image-prompt.md)。正式游戏资产仍需按以上规格逐项制作与验证。

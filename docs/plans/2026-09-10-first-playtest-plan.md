# 撸铁大亨 (Iron Tycoon) — 首轮 5 人真实玩家试玩方案 (Playtest Protocol)

> **文档状态**：已就绪 (Ready for Execution)  
> **制定日期**：2026-09-10  
> **测试版本**：Godot 4.7.1 / macOS 桌面版（基于当前稳定提交，UI 与素材冻结）  
> **测试目标**：在完全无设计文档、无内部指导的盲测条件下，验证玩家能否自主理解核心循环，评估“首次找到指导入口时间、误操作率、等待疲劳感、角色/器械辨识度及 Day 2 留存意向”。

---

## 1. 测试原则与边界说明

1. **零先验知识（Zero-Doc Blind Test）**：测试者不得提前阅读任何 GDD、系统设计或内部操作指南。
2. **纯观察与无提示介入**：除提供基础按键表（`WASD` 移动、`E` 交互、`Space` 暂停、`H` 热图开关）外，主持人全过程保持沉默，仅记录操作路径与困惑表情，禁止引导操作。
3. **素材与 UI 稳定冻结**：
   - 保持当前默认构图（32° 浅斜俯视）、默认紧凑 UI 与默认场景布局；
   - 严格禁止在测试期间临时增减 NPC、器械种类或装饰元素。
4. **单轮精修决策导向**：测试结束后汇总 5 人痛点，只收敛出**一项最高优先级的核心美术精修**（优先在：人物负重俯身姿态 / 脚底落脚锚点 / 器械材质协调性中三选一），杜绝发散。

## 3. 测试环境与标准化流程 (Procedure)

### 3.1 运行环境配置
- **操作系统**：macOS 桌面环境（Retina 屏幕缩放或标准 1080p 窗口，统一以 1280×720 视口运行）
- **输入设备**：标准键盘 + 鼠标（外接机械键盘与触控板/鼠标均可）
- **音频设备**：立体声耳机（音量统一调整至 65%，确保能听清环境白噪与 BGM）
- **录屏与计时**：后台 30 FPS 无损屏幕录制（含系统音频与麦克风旁白记录）

### 3.2 标准任务指引卡（提供给玩家的唯一纸质/屏幕文本）
> **《撸铁大亨》经营指引**：  
> 你是这家社区健身馆的馆长兼总教练。今晚是你接手的第一天营业。  
> - **移动**：`W` `A` `S` `D` 或方向键  
> - **互动 / 确认**：`E` 键  
> - **紧急叫停**：`Space` 空格键（暂停/继续）  
> - **巡视热图**：`H` 键（查看器械分布与使用情况）  
>  
> 请照看好你的会员，顺利完成第一天的晚间营业！

### 3.3 流程节点与目标任务 (Tasks)
1. **Task 1: 开门迎客** —— 启动游戏，观察场景，理解当前处于准备状态，主动前往或按键开启营业。
2. **Task 2: 巡视与识别状态** —— 观察进入健身房的会员，自主区分正在锻炼、排队等待与出现疲惫/困惑需要帮助的人员。
3. **Task 3: 首次完成指导** —— 走到出现互动标记或疲惫动作的会员身边，按下 `E` 键打开指导气泡，做出指导选择并完成一次动作教学。
4. **Task 4: 理解团体课节奏** —— 当团体课程提醒出现时，观察学员集结、换站与结课状态，体会课程节奏。
5. **Task 5: 营业打烊与结算** —— 等待营业结束，阅读今日收入与结算卡片，形成对第二天营业内容的预期。

## 4. 观察量化指标与评估维度 (Metrics & Rubrics)

### 4.1 硬性定量指标 (Quantitative Metrics)
- **T1: 首次指导达成耗时 (Time to First Guidance)**：
  - 定义：从第一位散客入场开始计算，到玩家成功触发并完成第一次会员指导的时长（秒）。
  - 基准目标：`< 45s` 为优，`45~90s` 为正常，`> 90s` 视为入口或指引存在严重认知障碍。
- **M1: 误操作频次 (Misoperation Count)**：
  - 统计非有效按键、在无对象区域狂按 `E`、走入死角卡墙、因 UI 遮挡误点击的次数。
- **W1: 等待发呆时长占比 (Waiting/Idle Ratio)**：
  - 在无任何教练交互或移动操作、仅纯看屏幕的单次最长静止时间（秒）。
- **R1: Day 2 续玩意向 (Day 2 Retention Intent)**：
  - 结算页面后直接询问：“如果现在继续，你想不想点开第二天？”（是 / 犹豫 / 否）。

### 4.2 主观量化打分 (1~5 分量表，5 分为极佳)
1. **视觉辨识度 (Readability)**：器械形态、人物动作、谁需要帮助是否一目了然？
2. **节奏舒适度 (Pacing)**：流程是松弛治愈，还是感到无事可做的无聊/疲劳？
3. **操作与反馈感 (Feedback)**：按键后角色的走动、靠近提示、指导成功的正反馈是否清晰及时？
4. **美术质感评价 (Art Appeal)**：相比同类像素游戏（如戴夫、开罗），画面氛围、光影与角色表演的吸引力如何？

## 6. 结果汇总与单项美术精修决策规则

试玩结束后，将 5 人数据录入矩阵表，按照以下规则自动裁决唯一精修方向：

| 现象聚合 | 主要归因 | 触发的唯一单项精修动作 |
|---|---|---|
| 玩家普遍反映“分不清谁需要指导”或“小人动作像在抽搐/不自然” | 人物动作表现力与疲惫/发力姿态辨识度不足 | **精修方向 A：核心人物动作与发力姿态**（重点调整卧推推胸起落幅度、深蹲/单车俯身重心、疲惫状态下的擦汗/垂头动作） |
| 玩家反映“小人悬空”、“踩不到地上”、“像漂在器械上” | 空间深度投影与接触锚点精度问题 | **精修方向 B：人物脚底落点与接触面阴影**（深化脚底 1px 接触深阴影与器械踏板的遮挡层级关系） |
| 玩家反映“器械像积木拼的”、“地板和器械混在一起不好看” | 器械材质细节与光影统一性欠缺 | **精修方向 C：四大器械材质与边缘高光协调**（优化金属管材反光高光、皮垫纹理消光与地垫区分度） |

> **红线原则**：  
> 坚决禁止同时执行 A + B + C；坚决禁止借由试玩反馈引入新 NPC、新剧情或新器械。必须在一个版本周期内单点突破，直到该项指标评分达到 4.5 分以上。
